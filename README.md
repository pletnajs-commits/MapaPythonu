# Mapa Pythonu — Python Map 🐍

**214 Python patterns, ordered from what you use every day to what you need once a year — each one runnable in the browser.**

## Features

- **Ordered by frequency** — daily, often, sometimes, rarely — so you learn the important things first.
- **Click a pattern** to see what it's for, its code and its real output.
- **Edit and run** the code right in the page (Pyodide), even offline.
- **Every line explained** — a comment after `#` says what each line does.
- **Pitfalls** marked with ❗ and the reason behind them.
- **Data-analysis scripts** — pandas, grouping, dates, charts — on made-up data.

Language: Czech.

## Under the hood

Every pattern is actually executed by a generator script and its real output is stored with it, so nothing on the page is invented. A build script assembles one static HTML page; Pyodide and packages are bundled for offline use.

The source is not public.
